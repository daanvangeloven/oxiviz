## Why oxiviz

<CardGrid>
	<Card title="Feedback warps" icon="star">
		Each frame is warped from the last one, so shapes smear, swirl and fold into kaleidoscopes instead of
		just bouncing to the beat.
	</Card>
	<Card title="Always different" icon="random">
		A scheduler keeps swapping warps and overlays, each with freshly randomized settings. A long track never
		settles into a loop.
	</Card>
	<Card title="Reproducible" icon="approve-check">
		All randomness comes from one seed. The same audio, seed and settings always render the same video.
	</Card>
	<Card title="Headless" icon="laptop">
		It renders on the CPU with no GPU or display, so it runs fine on servers and in containers. ffmpeg handles
		decoding and encoding.
	</Card>
</CardGrid>
